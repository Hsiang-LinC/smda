# SMDA Component Inventory

Status: current implementation map
Last verified: 2026-08-07

This is the durable map from product responsibilities to their source,
packaging, and consumer boundaries. Detailed behavior contracts live in
`contracts.md`; architectural reasons live in `architecture-rationale.md`.

## Product Topology

| Artifact | Residence | Responsibility | Consumer boundary |
|---|---|---|---|
| SMDA application source | `packages/scheduler/src/smda_scheduler/` | scheduler, workflow engine, Runtime Ledger, daemon, CLI, MCP, adapters | built into the standalone runtime; never copied into target repos |
| Sandcastle runner source | `packages/sandcastle-runner/` | isolated typed role-attempt execution | bundled as JavaScript in the plugin; still requires Node |
| SMDA plugin source | `plugins/smda-automation/` | Codex/Claude manifests, setup skill, MCP registration, runtime launcher | installed into the agent runtime's versioned plugin cache |
| Standalone macOS runtime | generated `runtime/bin/darwin-{arm64,x86_64}/smda/` | self-contained Python 3.12 application used by CLI and MCP | selected by `runtime/smda`; consumers do not need Python or uv |
| Private distribution | `Hsiang-LinC/smda-plugin-dist` | installable marketplace snapshot and immutable release tags | authorized users install it through the Codex marketplace CLI |
| Target-repo SMDA surface | generated by `setup-smda-automation` | repo config, harness routing, gates, ignored runtime state | config and pointers only; no engine or dependency copy |

## Scheduler Application

The Python package is intentionally flat. The important ownership seams are:

| Files | Responsibility |
|---|---|
| `scanner.py`, `scheduling.py`, `candidate_routing.py`, `route_dispatch.py` | scan eligible backlog work, apply dispatch gates, and route Task/Child/Parent/Roadmap candidates |
| `workflow.py`, `workflow_engine.py`, `workflow_registry.py`, `workflow_graph.py` | interpret Workflow Definitions and own typed graph behavior |
| `phase_ledger.py`, `role_attempts.py`, `reconciliation.py` | durable Runtime Ledger truth, semantic Attempt History, transactional effects, and recovery |
| `runtime.py`, `runtime_factory.py`, `workspace_tick.py` | compose adapters and execute one configured scheduler tick |
| `daemon.py`, `cli.py`, `__main__.py` | long-running drain loop and operator CLI entrypoints |
| `mcp_server.py` | expose product-owned operator tools over MCP without requiring repo config at server startup |
| `linear_backlog.py`, `local_ledger_backlog.py`, `backlog.py` | shipped backlog adapters and their shared boundary |
| `sandcastle_execution.py`, `adapters.py`, `execution_modes.py` | execution-adapter protocol and Sandcastle/default execution wiring |
| `context_packets.py`, `skill_loader.py` | assemble durable/static agent context and methodology references |
| `git_integration.py`, `parent_acceptance.py`, `roadmap_publication.py` | integration, acceptance, and ordered roadmap publication effects |
| `role_contracts.py`, `schema_artifact.py`, `schemas/role_schemas.v1.json` | Python role metadata and the generated cross-runtime schema artifact |
| `config.py`, `boot.py` | validate repo config, version contracts, and startup dependencies |

## Sandcastle Runner

| Path | Responsibility |
|---|---|
| `packages/sandcastle-runner/src/cli.ts` | JSON request/result-file process boundary used by the Python adapter |
| `packages/sandcastle-runner/src/runRoleAttempt.ts` | create worktree/sandbox attempts, invoke the agent, and return typed results |
| `packages/sandcastle-runner/src/roleContracts.ts` | resolve generated role-result schemas for structured output |
| `packages/sandcastle-runner/tests/` | protocol, worktree, schema-parity, and execution regressions |

`scripts/sync_plugin_runtime.py` produces
`plugins/smda-automation/runtime/js/sandcastle-runner.mjs`; the packaging gate
prevents source/bundle drift.

## Plugin Package

```text
plugins/smda-automation/
├── .codex-plugin/plugin.json
├── .claude-plugin/plugin.json
├── .mcp.json
├── skills/setup-smda-automation/
└── runtime/
    ├── smda
    ├── js/sandcastle-runner.mjs
    └── bin/
        ├── darwin-arm64/smda/     # generated release payload
        └── darwin-x86_64/smda/    # generated release payload
```

- `runtime/smda` selects the native architecture and fails clearly on an
  unsupported platform or incomplete installation.
- `.mcp.json` invokes `runtime/smda mcp`; CLI and MCP therefore use the same
  application and dependencies.
- `setup-smda-automation` owns Tier-3 onboarding and refresh only. It does not
  duplicate scheduler, adapter, schema, or generic harness code into a target
  repository.

## Build and Distribution

| Path | Responsibility |
|---|---|
| `scripts/build_standalone_runtime.py` | build one native PyInstaller onedir application and include package data |
| `.github/workflows/build-plugin-runtime.yml` | validate the requested manifest version, build both native architectures, assemble the plugin, verify the allowlist, and publish atomically |
| `.agents/plugins/marketplace.json` | Codex marketplace manifest copied into the distribution repository |
| `.claude-plugin/marketplace.json` | Claude Code marketplace manifest copied into the distribution repository |
| `distribution/README.md` | distribution-specific installation documentation |

The source repository owns code, tests, manifests, and workflow definitions.
The private distribution repository owns only the complete installable plugin,
marketplace manifests, README, `main`, and immutable `v<version>` tags. It does
not receive source history, `.venv`, `node_modules`, tests, or PyInstaller work
files.

## Stable Boundaries

- Scheduling and workflow decisions are deterministic product code, not a
  skill prompt.
- Sandcastle, backlog systems, and repo-context discovery remain adapters.
- Runtime state lives in the Runtime Ledger; backlog state is a projection.
- A target repo carries SMDA configuration and routing, not an engine copy.
- The installed plugin carries the standalone app, setup skill, MCP server
  registration, and Sandcastle runner artifact.
